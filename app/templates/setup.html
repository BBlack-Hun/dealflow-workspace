발송 에이전트 설치

카톡방은 각자 계정에 있어, 실제 전송은 내 PC에서 실행되는 에이전트가 담당합니다. 아래에서 내려받아 실행하면 이 화면과 자동으로 연결됩니다.

① 내려받기

⬇ Windows용 다운로드 ⬇ macOS용 다운로드

서버 주소와 내 토큰이 이미 채워진 상태로 내려받아집니다. 설정 파일을 손댈 필요 없습니다.

② 설치 · 실행 (Windows)

  1. 압축을 풀고 setup.bat 더블클릭 (최초 1회, 몇 분 소요)
  2. 카카오톡에 로그인
  3. run_agent.bat 더블클릭 → 검은 창을 켜둔 채로 두기
  4. 이 화면 왼쪽 아래 배지가 “발송 에이전트 연결됨” 으로 바뀌면 준비 완료

Python 이 없으면 python.org 에서 설치하세요. 설치 화면에서 “Add python.exe to PATH” 를 반드시 체크해야 합니다.

② 설치 · 실행 (macOS)

  1. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 에서 터미널 허용
  2. 압축 푼 폴더에서: 
    python3 -m venv .venv-agent
.venv-agent/bin/pip install requests pyyaml pyobjc-framework-Quartz
.venv-agent/bin/python -m agent.main --config agent/config.yaml

토큰은 내 계정의 발송 잡만 받아오는 열쇠입니다. 다른 사람과 공유하지 마세요.

주의

  • 발송 중에는 마우스·키보드를 건드리지 마세요. 카톡 창을 자동 조작합니다.
  • 테스트는 반드시 나와의 채팅 등 안전한 방으로 하세요.
  • 방 제목이 정확히 일치할 때만 전송되며, 다르면 그 건은 실패 처리되고 엉뚱한 방으로는 가지 않습니다.
  • 카카오 운영정책상 자동화는 계정 제재 소지가 있습니다. 발송 간격·상한을 임의로 줄이지 마세요.
