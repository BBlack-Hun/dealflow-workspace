  dealflow 발송 에이전트 (Windows)
════════════════════════════════════════════════

이 프로그램은 웹에서 만든 "발송 목록"을 받아서
내 PC의 카카오톡으로 딜소개 문구를 자동 전송합니다.

┌──────────────────────────────────────────────┐
│  서버(웹)          →  이 에이전트  →  카카오톡  │
│  무엇을 보낼지 결정     받아서 전송     실제 발송  │
└──────────────────────────────────────────────┘


■ 처음 한 번만
──────────────────────────────────────────────
  1) Python 설치 (없다면)
     https://www.python.org/downloads/
     ※ 설치 화면에서 "Add python.exe to PATH" 반드시 체크

  2) "1_최초설치.bat" 더블클릭
     → 몇 분 기다리면 "설치 완료" 메시지


■ 매번 사용할 때
──────────────────────────────────────────────
  1) 카카오톡 로그인 (켜두기)

  2) "2_에이전트실행.bat" 더블클릭
     → 검은 창이 뜨고 "서버 연결" 상태가 됨
     → 이 창은 켜둔 채로 두세요

  3) 브라우저에서 서버 접속
     http://192.168.0.122:8889

  4) [딜소개 보내기] 에서 기업/담당자 선택 후
     [발송 목록 생성] 클릭

  5) 카카오톡이 자동으로 움직이며 발송됩니다


■ 중요 주의사항
──────────────────────────────────────────────
  ▶ 발송 중에는 마우스/키보드를 건드리지 마세요.
    카톡 창을 자동 조작하기 때문에 방해하면 실패합니다.
    (150명이면 약 8~10분 소요)

  ▶ 테스트는 반드시 "나와의 채팅" 같은 안전한 방으로.
    실제 투자사 방으로 테스트하지 마세요.

  ▶ 방 제목이 정확히 일치해야만 전송됩니다.
    조금이라도 다르면 그 건은 실패 처리되고
    엉뚱한 방으로는 절대 가지 않습니다. (오발송 방지)

  ▶ 카카오 운영정책상 자동화는 계정 제재 소지가 있습니다.
    발송 간격(3~7초)과 상한(60건)을 임의로 줄이지 마세요.


■ 설정 바꾸기
──────────────────────────────────────────────
  agent\config.yaml 파일을 메모장으로 열어서 수정

  server_url : 서버 주소 (기본 http://192.168.0.122:8889)
               서버 PC의 IP가 바뀌면 여기를 수정
  token      : 에이전트 토큰 (웹에서 발급)

  카톡 창이 늦게 떠서 실패가 잦으면
  kakao_windows 아래 대기시간 값을 늘리세요.
  (예: after_open_room: 1.2 → 2.0)


■ 문제가 생기면
──────────────────────────────────────────────
  · "서버 연결 안 됨"
    → 브라우저에서 http://192.168.0.122:8889 가 열리는지 확인
    → 안 열리면 서버 PC(Mac)가 켜져 있는지, 같은 공유기인지 확인

  · "room_mismatch" 실패
    → 카톡방 제목과 등록된 이름이 다름
    → 웹에서 담당자의 카톡방 이름을 실제와 똑같이 수정

  · "input_not_filled" / "send_not_confirmed"
    → 붙여넣기나 전송이 확인되지 않음 (전송은 안 됨)
    → config.yaml 의 대기시간을 늘려보세요

  · 로그 파일: agent_logs\ 폴더
