# dealflow — 현재 초안(v0.2) 참조 + 사용자 피드백/요구사항

> 이 문서는 사용자가 제공한 HTML 화면 초안(v0.2 "딜소싱 워크스페이스")과 피드백,
> 자동화 개발 리스트를 정리한 **기획 입력물**이다. 기획 에이전트(fable5)와
> 개발 에이전트(opus)는 이 문서를 근거로 삼는다.

## 제품 정체성
- 이름(초안): **딜소싱 워크스페이스** — "투자 영업 관리"
- 사용자: **VC 영업 담당자**. 스타트업(=IR 기업)을 **투자사 담당자**에게
  **카카오톡으로 딜소개(딜 안내) 발송**하고, IR 자료 요청·미팅·후속을 관리한다.
- 핵심 업무 흐름: IR 기업 DB에서 소개할 기업 선택 → 인사문구 + 기업 요약문 자동 조합
  → 카톡 연결된 투자사 담당자들에게 발송 → 반응/IR 요청/미팅/후속(미팅 후 알림) 관리.

## 역할(Role)
- **사용자(user)**: 본인 담당 투자사/딜소개/체크리스트 관리.
- **관리자(admin)**: 전체 사용자 활동 집계(읽기 전용) — 개인 업무 체크리스트/딜소개 원문은
  관리자에게 노출하지 않고 집계 수치만 본다.

## 화면 구성 (초안 기준)
### 사용자 화면
1. **업무 체크리스트(u-check)**: 요일 루틴 기반 자동 생성되는 오늘 할 일.
   - 예: 홍보 메일 발송, 이메일 관리, 딜소개+리마인드 카톡, 전화 업무, 미팅 조율, IR 요청 처리.
   - 완료 시각/건수, 반복 루틴(화·목 등), 이번 주 요약(발송/메일/신규연결/IR전달).
2. **IR 요청·미팅(u-req)**: IR 자료 요청 트래커 + 미팅 파이프라인.
   - IR 요청: 요청일/투자사·담당/요청 기업/기한(D+N)/상태(미전달·전달완료)/[IR 전달] 버튼.
   - 미팅 파이프라인: 대상 기업/경과/상태(조율중·일정 제안·완료·Drop)/다음 액션.
3. **내 투자사(u-vc)**: 투자사 담당자 목록(=고객). 표 형태.
   - 컬럼: 담당자/투자사, 채널(카톡/메일), 투자 성격(단계·섹터), 최근 딜소개, 반응(IR/미팅), 상태(활발·반응없음·검토중단).
   - 필터: 전체 / 카톡 연결 / 메일만 / 반응 없음.
4. **IR 기업 DB(u-su)**: 소개할 스타트업 DB.
   - 컬럼: 기업, 사업 분야, 최근 매출, 누적 투자, 유치 희망, Pre Value, 딜 요약문(작성 상태).
   - 필터: 전체 / 딜소개 가능 / 요약문 미작성 / 정보 부족.
5. **딜소개 발송(u-deal)**: 핵심 화면.
   - 이번 회차 기업 선택(3개, IR 기업 DB 연동) → 내 인사문구(사용자별 저장) + 딜 요약문 자동 조합
   - 발송 대상(카톡 연결 담당자 중 선택) → 카톡 미리보기 → [발송 목록 생성].
   - 투자 성격 태그와 안 맞는 조합 발송 전 경고(예: Seed 전문 담당자에게 Pre-IPO 딜).

### 관리자 화면
- **전체 현황(admin-dash)**: 사용자별 활동 요약(연결 투자사, 딜소개 발송 수, 홍보메일, IR 처리, 미팅, 주간 목표 달성률), 주간 보고 내보내기.

## 사용자 피드백 (반드시 반영)
### 이미지 1 — 딜소개 발송 화면
- **좌측 메뉴 단어 수정**: 실제 업무에 맞는 메뉴 명칭으로 다듬기.
- **본문 텍스트 폰트 통일**: 화면 본문 텍스트를 하나의 동일 폰트로 정리(현재 혼용된 폰트 제거).

### 이미지 2 — 내 투자사(엑셀 시트) 화면
- **PC 한 화면에 표 전체가 한눈에 보이게**: 가로 스크롤 없이 한 페이지 레이아웃.
- **항목(컬럼/카테고리)별 필터링(드롭다운)** 제공.

## 개발/자동화 리스트 (핵심 목표)
> **개발 언어: Python. 최우선 목표: 카카오톡 딜 안내(딜소개) 발송 자동화.**
1. **카톡 딜소개 자동화** — 인사문구 + 기업 요약문 3개를 조합해 대상 담당자들에게 발송(문구 치환).
2. **IR 요청 자동 응대** — IR 요청한 투자사에 [IR 현황·딜소개 문구·보고서] 및 **IR 파일(첨부)을
   해당 카톡방에 자동 첨부/전송**.
3. **항목별 필터링(드롭다운)** — 투자사/기업 목록 등 표에 컬럼별 필터.
4. **투자사 관리 시트 PC 한 페이지 표시** — 가로 스크롤 없이 한눈에.
5. **IR 미팅 후 10일 알림** — 미팅 후 10일 경과 시 문자(SMS) 또는 카톡 알림.
6. **로그인/계정** — 휴대폰 번호 기반 로그인, 퇴사 시 계정/데이터 삭제 가능.

## 기술 검증이 반드시 필요한 최대 리스크
- **카카오톡 발송/파일 첨부 자동화의 실제 실현 방법**:
  - 카카오 공식 API(알림톡/친구톡, 카카오 로그인 메시지 API)의 가능/한계(사업자 채널·템플릿 승인·친구 동의·비용),
  - vs **PC 카카오톡 데스크톱 UI 자동화(pywinauto/pyautogui, Windows 전용)** — 임의 채팅방에 파일 첨부가
    가능한 유일한 현실적 경로일 수 있음.
  - **개발 환경은 macOS, 실제 사용/카톡 실행 환경은 Windows PC**로 보임(초안 스크린샷이 Windows Edge).
    이 플랫폼 격차를 아키텍처로 어떻게 해소할지 반드시 설계.
